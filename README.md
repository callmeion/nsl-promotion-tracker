# Promotion Tracker · NSL FOODS PCL

เว็บ static (HTML/CSS/JS) ติดตามรายชื่อผู้ได้รับการเสนอเลื่อนตำแหน่ง และสถานะการสัมภาษณ์
ดึงข้อมูลจาก `data/promotion.xlsx` ใน repo เดียวกันอัตโนมัติเมื่อเปิดหน้าเว็บ

## โครงสร้าง
```
index.html            หน้าเว็บ (Login + Dashboard)
assets/config.js      ตั้งค่า: ชื่อไฟล์ Excel, hash รหัสผ่าน, รายการสถานะ
assets/style.css      ธีม/สี CI (แก้ตัวแปรสีที่ :root), ฟอนต์ Kanit
assets/app.js         ตรรกะทั้งหมด
data/promotion.xlsx   ไฟล์ข้อมูลที่หน้าเว็บอ่าน (ตอนนี้เป็นข้อมูลตัวอย่าง)
data/
```

## เริ่มใช้งานบน GitHub
1. สร้าง repo แล้ว push ไฟล์ทั้งหมด
2. Settings → Pages → Deploy from a branch → `main` / root
3. วางข้อมูลจริงลง `data/promotion.xlsx` (ใช้รูปแบบตาม template) แล้ว commit — หน้าเว็บจะอ่านไฟล์ใหม่ทุกครั้งที่เปิด
ทดสอบในเครื่อง: `python -m http.server 8000` แล้วเปิด http://localhost:8000 (ต้องเปิดผ่าน server ไม่ใช่ file://)

## รหัสผ่าน
แก้ที่ `assets/config.js` → `passwordHash` (SHA-256 ของรหัส) วิธีสร้าง hash มีคำอธิบายในไฟล์
รหัสเริ่มต้น N@sl2026 · **หมายเหตุ:** เป็นการกั้นหน้าเว็บฝั่ง client เท่านั้น ไฟล์ Excel ใน repo ยังเข้าถึงได้ตรงจาก URL หากเป็นข้อมูลลับจริงควรใช้ private repo + hosting ที่มีระบบยืนยันตัวตน

## การอัปเดตสถานะ
หน้าเว็บเป็น Dashboard แบบอ่านอย่างเดียว — กรอกสถานะ (คอลัมน์ V–Y) ใน Excel แล้ว commit ไฟล์ใหม่ หน้าเว็บจะแสดงข้อมูลล่าสุดอัตโนมัติ
สถานะมาตรฐาน: ยังไม่สัมภาษณ์ / นัดสัมภาษณ์แล้ว / สัมภาษณ์แล้ว (รอผล) / ผ่าน / ไม่ผ่าน

## โหมดนำเสนอ
ปุ่ม "พิมพ์ / PDF" จัดหน้า A4 แนวนอนให้พร้อมบันทึกเป็น PDF
